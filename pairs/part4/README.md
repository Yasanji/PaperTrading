# Part 4 (working): flows and positioning

`get_cot.py` downloads CFTC Commitments of Traders history; `pit_demo.py` builds speculators' net positioning for six futures markets and downloads prices; `pit_bt.py` trades the same weekly signal from Tuesday (the date the report describes, i.e. hindsight), Friday close (after publication) and Monday close; `pit_chart.py` draws the comparison.

Result, Jan 2019 to Sep 2026: dating trades to Tuesday flatters the result by about 1% a year. The pre-registered contrarian test (2010 to 2018) is recorded in the Part 4 working notes and has not been run yet.
